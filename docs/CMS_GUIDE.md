# Руководство по CMS (Django Admin)

## 🎨 Что такое CMS в этом проекте

**CMS = Django Admin** с кастомизированным интерфейсом на базе **Django Suit** (красивая тема для админки).

В отличие от отдельных CMS (WordPress, Joomla), здесь CMS встроена в Django и доступна через админ-панель.

---

## 🔐 Вход в CMS

### Данные для входа (созданы для вас):

```
URL:      http://localhost/admin/
Email:    admin@test.ru
Password: admin123
```

⚠️ **ВАЖНО:** После первого входа смените пароль!

### Особенности входа:

1. **Вход по EMAIL**, а не по username
2. Email регистронезависимый (можно вводить ADMIN@TEST.RU или admin@test.ru)
3. Если забыли пароль - создайте нового пользователя через shell

## 📋 Что можно управлять в CMS

### 1. 📄 Контент (Content)

#### Страницы (Pages)
- Статические страницы сайта
- URL вида: `/page/slug/`
- Поля: заголовок, slug, содержание, SEO
- Редактор: TinyMCE (WYSIWYG)

**Пример использования:**
- Страница "О доставке"
- Страница "Контакты"
- Страница "Политика конфиденциальности"

#### Новости (News)
- Новости компании
- URL вида: `/news/slug/`
- Поля: заголовок, дата, содержание, изображение
- Категории новостей

**Пример:**
- "Открытие нового склада"
- "Акция к 23 февраля"

#### Статьи (Articles)
- Статьи и блог
- URL вида: `/articles/slug/`
- Поля: заголовок, категория, содержание
- Теги статей

**Пример:**
- "Как выбрать экскаватор"
- "Обзор новой модели XCMG"

## 🎯 Основные возможности

### WYSIWYG редактор (TinyMCE)

Для редактирования текста используется **TinyMCE** - визуальный редактор:
- Форматирование текста (жирный, курсив, заголовки)
- Списки (нумерованные, маркированные)
- Вставка изображений
- Вставка ссылок
- Вставка таблиц
- Вставка видео
- HTML режим для продвинутых пользователей

### Загрузка изображений

Поддержка изображений:
- **Easy Thumbnails** - автоматическое создание превью
- Адаптивные размеры (30+ предустановленных размеров)
- Оптимизация изображений
- Поддержка форматов: JPG, PNG, WebP

### SEO оптимизация

Для каждой страницы можно настроить:
- **Title** - заголовок страницы (в браузере)
- **H1** - главный заголовок на странице
- **Meta Description** - описание для поисковиков
- **Keywords** - ключевые слова (опционально)
- **Slug** - ЧПУ URL (человекопонятный URL)

## 📚 Как работать с CMS

### Создание новой страницы

1. Откройте **http://localhost/admin/**
2. Войдите с данными: `admin@test.ru` / `admin123`
3. Найдите раздел **Content → Pages**
4. Нажмите **Add Page** (Добавить страницу)
5. Заполните поля:
   - **Title** (Заголовок): "О доставке"
   - **Slug**: "delivery" (автоматически из title)
   - **Content** (Содержание): текст через визуальный редактор
   - **Meta description**: "Информация о доставке товаров"
6. Нажмите **Save** (Сохранить)

Страница будет доступна по адресу: `http://localhost/page/delivery/`

---

### Создание новости

1. **Content → News → Add News**
2. Заполните:
   - **Title**: "Открытие нового склада"
   - **Slug**: "new-warehouse"
   - **Category**: выберите или создайте категорию
   - **Content**: текст новости
   - **Main Photo**: загрузите изображение
   - **Publication Date**: дата публикации
   - **Is Published**: ✅ (чтобы показать на сайте)
3. **Save**

Новость будет доступна: `http://localhost/news/new-warehouse/`

---

### Добавление баннера

1. **Banners → Add Banner**
2. Заполните:
   - **Title**: "Летняя распродажа"
   - **Image Desktop**: изображение для десктопа (1920x600 рекомендуется)
   - **Image Mobile**: изображение для мобильных (768x400)
   - **Link**: ссылка на страницу акции или категорию
   - **Order**: порядок (1, 2, 3...)
   - **Is Published**: ✅
3. **Save**

Баннер появится на главной странице.

---

### Изменение настроек главной страницы

1. **Content → Homepage Settings**
2. Отредактируйте:
   - Основной текст
   - Контакты менеджеров
   - SEO настройки
3. **Save**

⚠️ **Обычно один объект Homepage** - редактируете существующий, не создаете новый.

---

### Управление заказами

1. **Orders → Orders**
2. Найдите нужный заказ
3. Откройте его
4. Измените статус:
   - Создан → Собирается → Отправлен → Выполнен
5. Просмотрите состав заказа (товары)
6. Просмотрите контакты покупателя
7. **Save**

## 🔧 Полезные функции админки

### Поиск

В каждом разделе есть поиск:
- Страницы: по заголовку, slug
- Новости: по заголовку, тексту
- Заказы: по номеру, email клиента
- Пользователи: по email, имени

### Фильтры

Боковая панель с фильтрами:
- **Новости**: по категории, дате публикации
- **Заказы**: по статусу, дате, способу оплаты
- **Товары**: по категории, бренду, наличию

### Массовые действия

Выберите несколько объектов и примените действие:
- Удалить выбранные
- Опубликовать/снять с публикации
- Изменить категорию

### Inline редактирование

Для некоторых моделей (например, товары в заказе) можно редактировать прямо в родительской форме без перехода на отдельную страницу.

## 🔐 Управление пользователями и правами

### Создание нового администратора

```bash
docker-compose exec web python manage.py shell
```

```python
from apps.users.models import User

user = User.objects.create_superuser(
    email='manager@metateks.ru',
    password='SecurePassword123'
)
print(f"Создан: {user.email}")
```

### Создание пользователя с ограниченными правами

1. **Users → Add User**
2. Заполните email и пароль
3. В разделе **Permissions**:
   - **Staff status**: ✅ (доступ к админке)
   - **Superuser status**: ❌ (не суперадмин)
   - Выберите конкретные права (permissions)

**Пример:** менеджер, который может только просматривать заказы:
- Права: `orders | order | Can view order`

## 🛠️ Решение проблем

### Проблема: "CSRF verification failed"

**Решение:** Проверьте настройки в `.env.docker`:
```env
CSRF_TRUSTED_ORIGINS=http://localhost http://127.0.0.1
```

Перезапустите контейнеры:
```bash
docker-compose restart web
```

### Проблема: Не могу войти

**Решение 1:** Проверьте email (вход по email, не username)

**Решение 2:** Создайте нового пользователя:
```bash
docker-compose exec -T web python manage.py shell << 'PYEOF'
from apps.users.models import User
User.objects.create_superuser(email='test@test.ru', password='test123')
print("Создан: test@test.ru / test123")
PYEOF
```

### Проблема: Изображения не загружаются

**Решение:** Проверьте права на директории:
```bash
docker-compose exec web chmod -R 777 /app/media
docker-compose restart web
```

### Проблема: "This field is required"

Если поле обязательное, но вы не хотите его заполнять:
- Проверьте модель (может быть `blank=True` не установлен)
- Заполните минимальное значение
- Обратитесь к разработчику для изменения модели

## 💡 Лучшие практики

### SEO

1. **Всегда заполняйте:**
   - Title (уникальный для каждой страницы)
   - Meta Description (150-160 символов)
   - H1 (отличается от Title)
   - Slug (понятный URL)

2. **Избегайте:**
   - Дублирования Title и Description
   - Слишком длинных заголовков (>60 символов)
   - Кириллицы в Slug

### Контент

1. **Структурируйте текст:**
   - Используйте заголовки (H2, H3)
   - Разбивайте на абзацы
   - Используйте списки

2. **Изображения:**
   - Оптимальный размер: до 500KB
   - Форматы: JPG (фото), PNG (логотипы)
   - Заполняйте alt-текст для SEO

3. **Проверяйте:**
   - Орфографию
   - Ссылки (не битые)
   - Актуальность информации
