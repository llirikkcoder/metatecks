## Git Коммиты
- НЕ коммить изменения без моего разрешения

## Общие правила
- Пиши все документы только на русском языке!
- Пиши чистый, поддерживаемый код
- Документируй сложные участки кода
- Следуй принципам DRY (Don't Repeat Yourself)
- Используй meaningful variable and function names
- Комментируй бизнес-логику, а не технические детали
